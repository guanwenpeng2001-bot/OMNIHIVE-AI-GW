# Security policy

## Supported versions

Security fixes target the latest stable release. For earlier installations, include the exact version in your report so maintainers can assess whether the current release is affected.

## Private reporting

Open a [private vulnerability report](https://github.com/guanwenpeng2001-bot/OMNIHIVE-AI-GW/security/advisories/new) through GitHub Security Advisories. Include the affected tag or commit, deployment mode, observed impact and the minimum information a maintainer needs to reproduce the issue in a disposable environment. Remove credentials, customer data and private endpoints from attachments.

Use the private advisory for follow-up, patch coordination and discussion of a disclosure date.
