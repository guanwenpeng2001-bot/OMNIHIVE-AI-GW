# Credential adapter

The gateway journal middleware installs the PostgreSQL validator. The shared native API-key middleware supplies the digest, action, client IP and group that passed identity ingress. A journal-enabled plan calls the resulting authorization function immediately before each generation send, including a detached image worker and a later WS turn. The function reads identity project or legacy scope, current key and user status, expiry, quota, group membership, key and group model policy, and IP rules. Only the digest lives in the request context.

connections and routing can replace these reads with their current credential and authorized routing ports. retirement can remove the adapter after HTTP, WS and job dispatch all use those ports and old gateway binaries have drained.
